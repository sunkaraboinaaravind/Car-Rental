# EliteDrive - Premium Car Rental System

A full-stack car rental application built with Spring Boot, React, and PostgreSQL.

## Features
- **Premium UI**: Modern glassmorphism design with animations.
- **Car Management**: View and filter available luxury cars.
- **Booking System**: Real-time price calculation and availability tracking.
- **Database**: PostgreSQL integration for persistent storage.

## Tech Stack
- **Backend**: Java 17, Spring Boot 3, Spring Data JPA, Lombok.
- **Frontend**: React, TypeScript, Vite, Framer Motion, Lucide Icons.
- **Database**: PostgreSQL.
- **DevOps**: Docker Compose.

## Getting Started

### Prerequisites
- Java 17+
- Node.js 18+
- Docker (for PostgreSQL)

### Setup Database
```bash
docker-compose up -d
```

### Run Backend
```bash
cd backend
# If you have Maven installed:
mvn spring-boot:run
```

### Run Frontend
```bash
cd frontend
npm install
npm run dev
```
